# 1분에디터

AcrossEditor. 보고 있는 홈페이지 탭을 위에서 아래까지 한 장으로 캡처하고, 새 홈페이지 방향에 맞는 제목, 배너, 설명, 버튼 문구를 만들어 복사합니다.

개인용 크롬 확장입니다. 별도 서버는 없고, 문구 생성은 브라우저에 저장한 Gemini 또는 OpenAI 키로 직접 요청합니다.

## 크롬에 넣기

1. 크롬 주소창에 `chrome://extensions` 를 엽니다.
2. 오른쪽 위의 개발자 모드를 켭니다.
3. 압축해제된 확장 프로그램을 로드합니다.
4. 이 폴더(`AcrossEditor`)를 선택합니다.
5. 도구모음의 1분에디터 아이콘을 누르면 측면 패널이 열립니다.

## 쓰는 순서

1. API 설정에 Gemini 키를 넣고 저장합니다. 키는 [Google AI Studio](https://aistudio.google.com/apikey)에서 만듭니다.
2. 참고할 홈페이지를 엽니다.
3. 이 탭이 메인인지 상세인지 고르고 전체 페이지 캡처를 누릅니다.
4. 만들 사이트의 방향, 상호, 말투를 적고 문구 만들기를 누릅니다.
5. 칸마다 복사를 눌러 아임웹 글자 칸에 붙여 넣습니다.

모델 이름을 비우면 Gemini는 `gemini-3.5-flash`, OpenAI는 `gpt-4.1-mini`를 사용합니다.
